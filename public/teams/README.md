# 팀 로고 디렉토리

메인 페이지 Hero 카드 워터마크용. **파일을 넣으면 빌드 시 자동 인식** — 별도 코드 변경 불필요.

## 파일 명명 규칙

`{shortName}.svg` — 사이트에서 쓰는 short 이름과 동일하게 (한글 OK).

| 파일명 | 팀 |
|---|---|
| `LG.svg` | 창원 LG |
| `DB.svg` | 원주 DB |
| `SK.svg` | 서울 SK |
| `KCC.svg` | 부산 KCC |
| `KT.svg` | 수원 KT |
| `소노.svg` | 고양 소노 |
| `정관장.svg` | 안양 정관장 |
| `현대모비스.svg` | 울산 현대모비스 |
| `가스공사.svg` | 대구 한국가스공사 |
| `삼성.svg` | 서울 삼성 |

## 권장 포맷

- **SVG 우선** — 확대 깨짐 없음, 파일 작음, 색상/투명도 자유
- PNG 가능하지만 SVG 추천
- 워터마크용이라 단색(monochrome) 또는 팀 컬러 그라데이션 SVG가 가장 잘 어울림
- 크기 무관 (Hero 카드에서 자동 리사이즈)

## 로고 구하는 곳

- KBL 공식 (kbl.or.kr) 각 팀 페이지 헤더
- 각 구단 공식 홈페이지
- 한국 위키피디아의 KBL 팀 항목 (SVG 형식 자주 있음)

## 동작

- 로고 파일이 있으면 → Hero 카드에 투명도 10% 워터마크로 표시
- 없으면 → 팀 약자 텍스트 SVG로 자동 fallback (예: "LG", "KCC")

## 저작권 주의

KBL 및 각 구단의 공식 로고는 저작권 보호 대상입니다. 개인용 분석 사이트의 워터마크 사용은 일반적으로 fair use 범위지만, 상업 배포·로고 변형은 별도 라이선스가 필요합니다.
